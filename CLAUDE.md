# Claude entry point

For homepage or other UI work, follow [the shared UI/UX direction](design/README.md), including the original user-supplied reference image. Apply its visual language across screens while preserving the NICU equipment workflows.

Follow [AGENTS.md](AGENTS.md) for shared claims, leases, work branches and reviews. Start with `npm run board -- list`, then claim a ready task before editing. The full usable 3D source is in `packages/scene/viewer/`; GLBs are in its `assets/` directory. Run `npm run dev` to explore locally. No access to the original hosted Site is needed.
